# Aura SCM - Supply Chain Management System

A specialized SCM solution designed for the Sri Lankan retail market, specifically modeled for *Keells Supermarkets*.

## 📊 Core Features
- *Keells-Specific Analytics:* Real-time tracking of LKR-based revenue and inventory.
- *Localized Supplier Management:* Integrated data for major partners like Cargills, Elephant House, and Maliban.
- *Demand Forecasting:* Predictive tools for inventory optimization.
- *Full-Stack Integration:* Built with React, TypeScript, and Supabase.

## ⚙️ Setup Instructions
1. Clone the repository.
2. Run npm install to install dependencies.
3. Create a .env file based on .env.example and add your Supabase credentials.
4. Run npm run dev to start the local server.
